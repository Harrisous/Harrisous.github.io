# Project STAR copy

The project cards use four fields in `data/rings.json`: `situation`, `task`,
`action`, and `result`. Each `description` is a one-sentence summary for callers
that do not render STAR. The 11 existing project descriptions and technology
lists supplied the content; this edit did not independently verify their metrics.
IDs, dates, links, images, and technology lists were preserved.

Editorial decisions:

- Results without an existing numerical outcome describe the delivered capability.
  No new performance measurements, awards, dates, or individual-role claims were added.
- Pido no longer claims to be fully offline. Its existing stack includes Google
  Web Speech API, so offline voice operation cannot be inferred from the supplied data.
- Slide Architect distinguishes the authorized-source restriction from its reported
  96% factual precision. The earlier claim of 100% factual integrity was removed.
- Clinical Claim Verifier's 100% and 77% accuracy figures are explicitly results
  from the project evaluation at the stated thresholds, not general clinical guarantees.
- Text-to-SQL retains the reported 50% improvement and the harder-query trade-off;
  the supplied description does not establish a percentage-point change.
- Sentinel's transaction and monthly-volume figures describe the project scope.
  They are not presented as a measured model-throughput benchmark.

Jemm Tec is outside this project-copy edit. Its experience details require the
user's clarification before new responsibilities or accomplishments are published.
